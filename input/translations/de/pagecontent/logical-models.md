### Logische Modelle

Das logische Datenmodell des Moduls **Dokument** beschreibt den fachlichen Datensatz unabhängig von der konkreten FHIR-Repräsentation. Der Datensatz-Kontext ist auf [Datensätze und Beschreibungen](datasets-and-descriptions.html) beschrieben.

{% include StructureDefinition-mii-lm-dokument-snapshot.xhtml %}

*Das Logical Model dient ausschließlich der Abbildung der Datenelemente und ihrer Beschreibungen. Die verwendeten Datentypen und Kardinalitäten sind nicht als verpflichtend anzusehen; sie werden abschließend durch die FHIR-Profile bestimmt. Für jedes Element des Logical Model existiert ein 1:1-Mapping auf ein Element einer konkreten FHIR-Ressource.*

Eine tabellarische Übersicht aller Elemente samt Beschreibungen — und das Mapping auf das Profil — bietet die Artefaktseite [MII LM Dokument](StructureDefinition-mii-lm-dokument.html) sowie die Mapping-Tabelle auf [Profile und Erweiterungen](profiles-and-extensions.html).
