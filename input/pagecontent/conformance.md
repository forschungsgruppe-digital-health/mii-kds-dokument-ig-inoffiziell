### Conformance

This page describes how conformance requirements are documented. A possibly newer version is
documented in the [core dataset wiki](https://github.com/medizininformatik-initiative/kerndatensatz-meta/wiki/Conformance).

#### Documenting requirements

Requirements in this specification are marked with the following capitalised keywords (conformance
verbs) based on [RFC-2119](https://datatracker.ietf.org/doc/html/rfc2119). The German column is
normative for the German pages and is therefore kept verbatim:

| German                       | English              |
|------------------------------|----------------------|
| MUSS / MÜSSEN                | MUST / SHALL         |
| DARF NICHT / DÜRFEN NICHT    | MUST NOT / SHALL NOT |
| VERPFLICHTEND                | REQUIRED             |
| SOLLTE / SOLLTEN             | SHOULD               |
| SOLLTE NICHT / SOLLTEN NICHT | SHOULD NOT           |
| EMPFOHLEN                    | RECOMMENDED          |
| KANN / OPTIONAL              | MAY                  |

The two other sections of this source page have their own pages in the page set:
[Must Support](must-support.html) and [Handling Missing Data](missing-data.html).
