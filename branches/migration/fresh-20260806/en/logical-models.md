## Logical Models

### Logical models

The information model of the **Dokument** module is represented as the FHIR logical model `mii-lm-dokument`. The corresponding dataset description with the element definitions is on [Datasets and Descriptions](datasets-and-descriptions.md).

**Note that the logical model aims solely at representing the data elements and their description. The data types and cardinalities used are not to be regarded as binding; that is settled by the FHIR profiles.**
